# Password Generator

A beginner-friendly Python command-line project that creates secure random passwords.

## Features

- Choose whether to include uppercase letters, numbers, and symbols.
- Always includes lowercase letters.
- Choose a password length from 8 to 128 characters.
- Guarantees at least one character from every selected type.
- Uses Python's `secrets` module for secure random choices.
- Validates answers and lets you generate passwords until you choose to quit.

## Run the project

1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

   ```bash
   python3 pass_gene.py
   ```

No extra packages are required.
